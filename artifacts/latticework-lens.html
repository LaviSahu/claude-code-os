The Latticework Lens

Run a real decision through the models — naming each so the reasoning is auditable. The point isn't consensus; it's finding where the models disagree, because that disagreement is where the clarity lives. Ends in vault-ready markdown.

"You've got to have models in your head, and you've got to array your experience — both vicarious and direct — onto this latticework of models."— Charlie Munger
01

State the decision

One sentence. The sharper the framing, the sharper the lens. Reserve the deep run for big or hard-to-reverse calls.

02

Choose your models

Pick 2–4 that are genuinely relevant — reach across disciplines, and include the non-obvious one. More isn't better; relevant is better.

0 selected · aim for 2–4
03

Walk each model

Answer the probe in each model's own voice. Write what the model actually says about this decision, not what you already want to do.

Select models above to begin the walk.
04

Find the disagreement, then decide

Where do the models disagree?

If every model points the same way, the decision was easy and you didn't need the lens. Name the real tension — which two models pull apart, and which one you're choosing to weight more, and why.
